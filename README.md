# Hotel Booking Data Analysis

## Project Overview
This project explores hotel booking data using Python, Pandas, NumPy, and data visualization libraries. The notebook focuses on inspecting and cleaning the data, exploring booking and guest characteristics, and visualizing patterns in market segments and arrivals.

## Dataset
The dataset used for this project was obtained from **Kaggle**.

https://www.kaggle.com/datasets/ahsan81/hotel-reservations-classification-dataset

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## Analysis Performed
- Inspected the dataset structure, columns, data types, and sample records.
- Identified records where both adult and child guest counts were zero.
- Checked for duplicate records and removed duplicates.
- Reviewed descriptive statistics for selected numerical features.
- Calculated percentile values for numerical features such as lead time, weekday nights, and special requests.
- Explored previous-cancellation and repeated-guest information.
- Examined market-segment distribution and visualized market segments alongside adult counts and reserved room types.
- Converted numeric arrival-month values into readable month names and created a month-level date field.
- Calculated total guests and explored guest counts by arrival date.

## Project File
- `Hotel_booking_data_analysis.ipynb` — Jupyter Notebook containing the project code, analysis, and visualizations.

## How to Run
1. Download or clone this repository.
2. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn plotly
   ```
3. Download the dataset from the Kaggle source linked above and place it where the notebook can access it.
4. Open the notebook in Jupyter Notebook.
5. Run the cells in order.
